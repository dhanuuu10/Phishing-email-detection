# Phishing Email Detection Dashboard

## Project Overview

This project is a machine-learning-based phishing email detection
dashboard. It analyzes email content and identifies potential phishing
indicators.

## Features

- Email phishing detection
- Machine learning classification
- Threat intelligence indicators
- Risk level assessment
- Phishing awareness center
- ML model evaluation
- Streamlit dashboard interface

## Technologies Used

- Python
- Streamlit
- Pandas
- Scikit-learn
- Joblib
- TF-IDF Vectorization
- Logistic Regression

## Machine Learning

The system uses a TF-IDF text vectorizer and Logistic Regression
classifier to classify emails as phishing or legitimate.

## Model Evaluation

The model is evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
- Classification Report
